EFFECTIVE DATE: 2023-02-15
SUBJECT: 2-Day Event Date Restriction

An order cannot be refunded within the final 2 days before its event, or at any point after the event has taken place.

To apply this policy, count the number of days from the current date to the event_date. Both are given in YYYY-MM-DD format. A positive count means the event is still ahead, and a negative count means it has already taken place.

If 2 days or more remain, the order is outside the restricted period and may be refunded, provided no other policy prevents it. If fewer than 2 days remain, or the event has already taken place, the request must be denied. An order at exactly 2 days is outside the restricted period.

This policy supersedes the Standard 14-Day Refund Policy. An order within the refund window must still be denied if it falls inside the restricted period.
